# One-Liner Laugh Lab

A program that writes one short funny line — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

It prints the character count and writes exactly one line of UTF-8 text (1–200 characters, no trailing newline).

Entry for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition on [make.fun](https://make.fun).
